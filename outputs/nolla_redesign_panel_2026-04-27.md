## セッション1: 「Nollaの最大の罠は何か」— 既存設計の何を捨てるか

**B（ゲームP）**: まず、現状のNolla v3設計と、Yuyaさんが過去に積み上げた4ゲーム＋8領域認知測定構成を全部一旦テーブルから降ろさせてください。0ベースなので。私が一番心配しているのは、Nollaが「ゲームに見える療育アプリ」になることです。療育アプリは絶対にハマらない。Mightierが100K kidsで頭打ちなのも、Otsimoが累計1M+ DLでもMAU 16K-30Kでアクティブ率1.6-3%なのも、本質的にはこれが原因です。「親が使わせる」アプリは続きません。「子どもが自分から開く」アプリだけが残る。

**A（CTO）**: 数学的にもそうですね。10M DLを3年で達成するには、月次オーガニックDLを概算で27万必要です。これはMightierの月次新規（推定2-3千）の100倍、Otsimoの10倍以上。**療育ニッチで取れる数字ではない**。Toca Boca的なエンタメ純度がないと到達不可能です。

**C（神経科学者）**: そこで私が強く主張したいのは、**「ゲームに見える療育アプリ」と「療育要素を裏に持つゲーム」は別物だ**ということです。後者は科学的にも倫理的にも正しい設計です。Mightierは前者寄り、Toca Bocaは後者の素朴版（実際UAB 2025のn=18探索研究で、自閉症児のアサーション上昇・問題行動減少が確認された）。Yuyaさんが言うように、目的は「親が良かったと思う＝子どもに何かしらの成長」。これは隠す必要はない、ただ**子どもにとっては療育がゼロに見える**ように作る。

**B**: 任天堂の言葉でいうと「裏でやってることが、表のおもしろさを邪魔しないか」が全てです。どうぶつの森が住人の好感度パラメータを裏でゴリゴリ計算しているのを子どもは知らない。けど住人と仲良くなった「実感」だけは残る。Nollaも同じ構造で作るべきです。

**【セッション1の結論】**:
- 現状のNolla（4ゲーム＋認知8領域測定）は捨てる。「テスト感」が消えていない設計だから。
- **新Nollaは「子どもにとっては純粋なオープンエンドの世界」、「親にとっては成長の証明書付きアプリ」、「裏では発達指標を計測している」の三層構造**。
- 「療育アプリ」と名乗らない。カテゴリ訴求は「**子どもの世界をつくる、AI発達コンパニオン**」のような、誰にでもピンと来る平易な日本語で表現する（業界用語・カタカナ造語は採用しない）。

## セッション2: 「コア体験の純度」— 18歳まで歪めないものは何か

**A**: 12社の研究で明らかになった**普遍法則の第1**は、コア体験を10年以上ブレずに守った会社しか10億DLには到達していない、ということです。Toca Boca = 15年「No rules / score / timer」、ABCmouse = 15年「Tickets経済 + Path」、Sago Mini = 13年「完全Open-ended + キャラ常駐」、Khan = 18年「無料 + Mastery Learning」。コア体験を破壊した瞬間に失敗が起きる。Toca Boca Daysのマルチプレイ化16ヶ月で永久終了、ABCmouseのFTC $10M罰金（解約導線改悪）、Dubuの「cognitive training」希釈でRCT負け。**Nollaが10年守る原則を3-5個に絞らないと、ロードマップ判断ができない**。

**C**: 私から3つ提案します。**(1) エラーレス学習の絶対遵守**（子どもに失敗体験を与えない、サイレント修正で正解への再提示）。**(2) 予測可能性の絶対遵守**（ルールは予告なしに変えない、世界の物理法則は不変）。**(3) 言語非依存の絶対遵守**（読めない子・日本語以外の子・将来のグローバル展開で文字依存設計をすると詰む）。この3つは神経科学的にもASD/IDの中核特性に対する設計境界で、例外なし。

**B**: ゲームデザイン側から2つ追加させてください。**(4) ゲームオーバーゼロ**（タイマー、減点、「間違い！」表示なし）。**(5) コレクションの決定論**（ガチャ・確率報酬は禁止。同じ行動には同じ報酬。これはASD児の予測可能性原則とゲームバランス両方から）。

**【コア原則5つ】（10年守る、絶対）**:
1. **エラーレス**: 失敗体験ゼロ。サイレント修正・4段階プロンプティング降下
2. **予測可能性**: ルール・物理・キャラ・UI配置は予告なしに変えない
3. **言語非依存**: 文字なし、アイコン＋アニメ＋短尺音声のみで全機能完結
4. **ゲームオーバーゼロ**: タイマー、減点、「不正解」表示なし
5. **コレクションの決定論**: ガチャ禁止、同行動＝同報酬

（解約導線の倫理性・ダークパターン排除は当然の前提。コア原則として明示する必要なし。ABCmouse FTC $10M罰金は反面教師として一般原則に内包）

これに違反する仕様は、どんなに収益が上がっても採用しない。

## セッション3: 「コア体験」— Nollaの中身は何にするのか

**B**: ここが本題です。私は12社の中で**Toca Life World × Sago Mini × Khan Academy Kids の融合**が最強解だと思っています。理由を順番に。

- **Toca Life World**: ハブ画面1枚に世界が並び、好きな世界に入って自由に遊ぶ。ルールも目的もない。Nolla World として継承。
- **Sago Mini / Khan Kids**: 常駐キャラがあらゆる世界に登場し、子どもが「相棒」を持てる。Khan Academy Kids の Kodi the Bear、Sago Mini の Jinja/Harvey/Robin が、**世界中の3-8歳が共通して反応する設計**であることが12社の事例で確定している。**ただしNollaは「常駐キャラを多数持つ」ではなく「常駐キャラは1体（AIコンパニオン役の導き手）+ ユーザーが作ったNollaが相棒として共に動く」構造を採る**（後述）。Sago型3-5体は MVP スコープ過剰、ASD児の予測可能性は1体の固定キャラでも十分担保される。
- **Khan Academy Kids**: 文字なしで完璧に機能する子ども向けUI、Journey Mode（進めると景色が変わる）、ご褒美ボックス開封（3つから1つ選ぶ）、キャラ部屋の段階充実。コア体験の完成度は12社で最高。

これにToca Boca型「キャラクター作成2,000+アイテム」を被せる（**ただし義肢・車椅子・補聴器対応は不採用**。Nollaの主対象はASD+IDで、物理的障害は別ニーズ。スコープを広げてもretention寄与は薄く、対象セグメントへの集中力を下げる）。子どもが**最初の5分で自分のNolla（分身）を作る**。これだけで、その子のNollaが18歳まで存在する。

**C**: 神経科学的に、この設計は正しい。**自分自身を表象した分身が世界に存在し続ける**ことが、ASD児にとっての安心の根源になる。それが18歳まで継続するなら、長期粘着の心理基盤になる。**ただし**、私は1つ条件を付けたい。Toca Bocaが学術的に弱いのは、**「自由すぎて何も習得しない」可能性がある点**です。重度の知的障害がある子は、構造化された足場（scaffolding）がないと、画面を眺めて終わる。だからNollaには **Khanの Mastery Learning（できるまで進ませない）の構造を裏で動かす**必要がある。表は完全Open-endedに見える、裏では8領域認知の習熟度が積み上がっていく、という二重構造。

**A**: 実装は？

**C**: 各小ワールド内のオブジェクトとのインタラクションが、自動的に8領域（注意・記憶・処理速度・実行機能・言語・社会性認知・運動制御・感情調整）の小タスクになっている。例えば「お買い物ワールド」で買い物カゴに入れる動作が、注意持続＋言語理解＋運動制御の3指標に自動マップされる。子どもにはタスクに見えない、ただの遊び。**Jade NDの8ドメイン構造を、Toca Bocaの世界に隠す**。これが私の提案するハイブリッドです。

**B**: そこに任天堂が入れたい要素を1つ。**「世界が育つ」感覚**。どうぶつの森の村が時間経過で変わるように、Nolla Worldも子どものプレイ蓄積で景色・住人・小物が増える。これは適応難度の隠蔽装置にもなる（難しさが上がるのではなく、世界が広くなる）。

**【セッション3の結論】**:
**Nolla = Toca Life Worldのハブ構造 + Khan Kids型「導き手キャラ1体（固定）」+ Toca Boca型「自作キャラ（Nolla=自分の分身、自作キャラがそのまま相棒）」+ Khan Mastery Learning（裏） + Vineland準拠 4領域評価（裏、後述） + どうぶつの森型「育つ世界」**。

## セッション4: 「親の成長実感」— 「使わせて良かった」をどう設計するか

**F（保護者代表）**: 私から正直なところを言わせてください。療育系アプリを試したことは何個もあります。「効いた気がする」と「効いた」は別物です。Otsimoを6ヶ月使った後、何が変わったのか説明できなかった。だから解約しました。一方でMightierを使ったとき、「家庭での癇癪が週3回から週1回に減った」というプリンターで印刷できるレポートが出てきて、それを夫と祖父母に見せた瞬間に、夫婦の合意ができた。これがLTVを伸ばした唯一の体験です。

**C**: 完全に正しい。これは**「成長の社会的可視化」**と呼びます。家庭内で子どもの成長は親（特に主介護者）にしか見えない。それが家族と社会に共有可能になった瞬間、サブスクの意味が「私のための課金」から「家族のための投資」に変わる。これがABCmouseが「Family Plan」、Mightierが「印刷可能レポート」で取った戦略です。

**A**: 設計に落とすと、Nollaの保護者ダッシュボードは3層構造であるべきです。

| 層 | 内容 | 頻度 | 形式 |
|---|---|---|---|
| **L1: 今週のできた** | 自然言語でのAIサマリ「今週、ヒロくんは『順番を待つ』を初めて自分から3回しました」 | 毎週 | LINEで届く、Slack的に短く |
| **L2: NCI（Nolla Cognitive Index）** | 8領域のレーダーチャート、過去比較、同年齢分布の中での位置 | 毎月 | アプリ内、専門用語なし、絵で表現 |
| **L3: 3ヶ月のNollaの記録**（事実観察ログ・命名から「成長証明書」を撤回） | 「楽しんだ世界トップ3」「夢中になった瞬間」「新しく挑戦したこと」「お気に入りキャラ/アイテム」を物語化。**LINE/Instagramで送れる短尺動画（30-60秒）+ PDFダウンロード**。**「成長」「改善」を売り文句にしない。退行・停滞時もハレーションを起こさない事実観察設計**。数値レーダーは見たい親だけがオプトインで開く格下げ層へ | 季節ごと | スマホ完結 |

**C**: ここで設計を1つ修正します。当初「成長証明書」という名称を提案しましたが、これは構造的にハレーションを生むので撤回します。**ASD+ID児の発達は線形ではなく、季節要因・体調・環境変化で Vineland スコアが下がることがある**。「成長」を売り文句にした証明書を季節ごとに発行すれば、停滞・退行時に親が「Nollaを使わせているのに伸びない」と自責し、退会理由化する。これは Mightier が「62% reduction」を全員に約束して構造的に抱えた問題と同根です。

**D（小児臨床リード）**: 修正案として、**「3ヶ月のNollaの記録」という中立観察ログ**に置き換えるべきです。コンテンツは「楽しんだ世界トップ3 / 夢中になった瞬間 / 新しく挑戦したこと / お気に入りキャラ・アイテム」の事実観察と物語化。**数値レーダーはデフォルト前面に出さず、見たい親だけが「もっと詳しく見る」で開けるオプトイン格下げ層**に置く。退行・停滞時のフレーミングはAIが個別文脈で「この時期は同じ遊びを繰り返している＝予測可能性で安定を取っている」「○○ができる前の基礎固めの時期」と正当な科学的解釈を与える（神経科学者監修テンプレ）。

**B**: ゲーム設計者として強く支持します。任天堂の「あつまれ どうぶつの森」が成功した理由の一つは、住人の好感度や島の発展度を**親しみのある語彙でしか見せない**こと。「成長」を売らずに「歩み」を渡す。これでハレーションゼロ、退会理由ゼロ、Mightierが構造的に解けなかった問題を超える設計になる。

**【親ダッシュボードに『約束』を持ち込まない原則】**: 「成長」「改善」「向上」を売り文句から外す。代わりに「歩み」「過ごした時間」「お気に入り」「挑戦」の中立語彙。媒体は2026年仕様（LINE/Instagram共有可能な短尺動画+PDF、紙印刷は売り文句にしない）。

**B**: 子ども側にも一個入れたい。**「自作Nollaからの手紙」**。子どもが言葉で表現できないので、**子ども自身が最初の5分で作ったNolla（自分の分身キャラ）が、その日のNolla Worldでの出来事をポジティブに報告する手紙を書く**（「ぼく、今日お買い物のせかいで、はじめて青いブロックをカゴに入れたよ。たのしかった！」）。代筆主体は事業者の Nolla ブランドではなく、**子ども自身が作ったキャラ**であることが核。これによりキャラ統合（自作Nolla=相棒）と世界観が一本化し、親にとっては「子どもが書いた手紙」感が増す。任天堂の「すれちがい通信」の原理を発達領域に転用し、**子どもの内面が言葉にならない苦しみを、子ども自身の分身が代弁する**装置になる。

**C**: トーンは「ポジティブ事実観察」に統一。退行・停滞時のフレーミング設計と整合し、「今日できなかったこと」は書かない。「今日した楽しいこと」「今日新しく試したこと」「今日お気に入りだったキャラ・アイテム」のみ。これでハレーションゼロ。

**F**: それ、欲しいです。

**【セッション4の結論】**:
親側のフィードバックは、**(L1)毎週LINE AIサマリ + (L2)月次4領域レーダー（オプトインで深掘り可能） + (L3)季節ごと「3ヶ月のNollaの記録」（事実観察ログ・短尺動画＋PDF・LINE/Instagram共有可） + (L4)自作Nollaからの手紙（子どもが作ったアバター・キャラが1日の出来事をポジティブに報告）**の4層で実装する。**「成長証明書」というネーミングは撤回**（停滞・退行時のハレーション回避）。**「成長」「改善」を売り文句にせず、「歩み」「過ごした時間」「お気に入り」の中立語彙で構成**。Mightierが紙レポートで実証した「家族・社会への可視化」効果を、2026年スマホUXで再構築しつつ、Mightierが構造的に解けなかった「効果が出ない親の離脱」問題も同時に解決する。

## セッション5: 「1M → 10M DLの装置」— スケール戦略

**A**: 普遍法則の第2は、**「創業者の個人原体験 + 1つの権威接続点 + 言語非依存設計」の三点セットがオーガニック獲得の核**でした。Yuyaさんには重度知的障害の姉がいて、その当事者ナラティブを構造化して10年語り続ける覚悟がある（メモリに残されたNolla思想史から確認できる）。これはOtsimoの弟Alperナラティブ、Speech Blubsの創業者吃音ナラティブと同等の核資産です。**Day 1からこのストーリーをコンテンツ化する**べきです。

**E（グロースマーケター）**: 三点セットの「権威接続点」をどう作るかは私の領域です。Mightierが10年たどったBoston Children's Hospital経路と同じものを、日本では**国立成育医療研究センター + 東京大学 IRCN（International Research Center for Neurointelligence）**の二点で押さえます。Phase 0で共同研究契約を結び、看板の上に乗ってPRしていく。Otsimoは現地教育省で、Speech BlubsはPioneers Festivalで、これをやった。Yuyaさんが「Nollaは医療路線に行かない」と決めても、**研究機関との共同研究は別物**であり、エビデンス層と権威層の両方を取りに行ける。

**B**: 当初、私は **TikTok UGC設計**（Toca Life World が10億DL到達した #tocabocaworld バイラルの転用）を提案しようとしました。が、このパネル内で**根本的に間違いだと気づいた**ので撤回します。

**F（保護者代表）**: それ、絶対に回りません。ASD+ID児の親はSNSで子どもの作品を公開しません。プライバシー懸念が定型児の親と桁違いに強い、子ども本人が動画パフォーマンスを苦手とする、「障害がある子の親」と知られたくない動機がある。実際 Otsimo / Mightier / Jade ND / Speech Blubs にUGCバイラル機能が一切ないのは、この発達障害ニッチでは構造的に成立しないからです。

**E（グロースマーケター）**: その代わり、このセグメントで**実証済みのバイラル経路は4つあります**。

| 経路 | 仕組み | 12社の実証 |
|---|---|---|

## セッション6: 「エビデンス」— 医療路線でなくても、どう示すか

**C**: Yuyaさんが医療路線に行かないと決めたのは賢明です。PMDAの医療機器プログラム（SaMD）認証は3-5年とコストで2-5億円かかり、その間にDL数が頭打ちになる（これはMightierが**FDA非取得を意図的に選んだ**理由でもある）。一方、医療路線に行かないからこそ、**観察研究レベルのエビデンスは Day 1 から積み上げる必要がある**。これが Sago Mini や Toca Boca が15年経っても抱える脆弱性です（Toca BocaはUAB n=18、Sago Miniは独立RCTゼロ）。

**D（小児臨床リード）**: 私から提案させてください。Nolla のエビデンス戦略は3階建てです。

| 階 | 内容 | 期間 | 費用感 | 目的 |
|---|---|---|---|---|
| **1階: 観察データ** | Nolla内のプレイログから8領域認知発達のlongitudinal data収集 | Phase 0から永続 | アプリ内蔵で限界費用ほぼゼロ | 集団としての発達曲線を可視化 |
| **2階: パイロット研究** | 国立成育＋東大IRCN協力で3-8歳ASD+ID 50名を6ヶ月追跡 | Phase 1で開始、12ヶ月で完了 | 2-3千万円（研究費・倫理審査含む） | 査読論文1本、Mightier型「実利用での改善エビデンス」獲得 |
| **3階: ランダム化比較試験 (RCT)** | n=200規模で12週間、対照群＝従来療育、主要評価項目＝適応行動・QOL | Phase 2で開始、18ヶ月で完了 | 5千万-1億円 | 国際査読誌掲載、グローバル展開時の通行手形 |

**重要な設計上の注意**: DubuのRCTが「優位性なし」で失敗した最大の理由は、**比較対照を「定型児向け一般教育アプリ」に取り、対象を全般認知発達という広すぎる主要評価項目で計った**ことです。Nollaは**(a)対象をASD+IDに限定（定型児を入れない）、(b)主要評価項目を「適応行動」と「QOL」（家庭での困りごと指数）に絞る**ことでこの罠を回避します。

**B**: ゲーム側からも一個。**「証拠は子どもの遊んだ姿そのもの」**。世界中で1億再生されたToca Life Worldの子どもの動画は、それ自体が「楽しい」という証拠です。NollaのTikTok/InstagramでバズるUGC動画は、**学術的エビデンスとは別の、社会的エビデンス**として機能する。両方を計画的に積む。

**A**: ユニットエコノミクスにエビデンス費用を組み込みましょう。

- Y1総研究費: 3,000万（パイロット）
- Y2-3: 1億（RCT）
- 累計1.3億 / Y3 10M DL × 仮に有料率5%・LTV ¥18,000 = 90億ARR
- エビデンス費用は売上の1.5%以下、十分にfundable

**【セッション6の結論】**:
1. **3階建てエビデンス戦略**（観察→パイロット→RCT）を Phase 0/1/2 に時系列配置
2. **対象 ASD+ID 限定、主要評価項目「適応行動」「QOL」**でDubu罠を回避
3. **国立成育＋東大IRCN を Phase 0 で確保**（権威ブランド × 学術エビデンス × 政府助成 の三役を1つの契約で取る）
4. **TikTok UGCを「社会的エビデンス」として並行運用**

## 統合: Nolla 0ベース設計書

ここまでの6セッションを統合し、Nollaの0ベース設計を以下に提示する。これは現状のv3設計を上書きし、新しい正となる。

### 1. プロダクト一行定義

> **Nolla は、3-18歳の発達特性とともに生きる子どものための、AI発達コンパニオン**。子どもにはルールも失敗もない自分だけの世界、保護者には子どもの歩みが言葉と物語で見える。

「療育アプリ」と名乗らない。「ゲーム」とも名乗らない。**「子どもがつくる自分の世界 × AI発達コンパニオン」**という、誰にでもピンと来る訴求でカテゴリを自ら立ち上げる（Toca Boca が「digital toy」を創出したのと同じ手法、ただし日本語話者にとって平易な語彙のみ使用）。

### 2. ターゲットセグメント

| 層 | 機能発達年齢 | 暦年齢 | 機能設計の視点 |
|---|---|---|---|
| **A. 幼児期** | 1-3歳 | 3-5歳 | 主に運動制御・注意・言語前段階。タップ大、文字ゼロ、即時反応必須 |
| **B. 学童前期** | 3-5歳 | 5-10歳 | 言語拡張・数概念・社会性認知の足場。Mastery Learning が裏で稼働 |
| **C. 学童後期〜思春期** | 5-10歳 | 10-18歳 | 自己調整・実行機能・長期目標管理。Mightier型HRV感情調整、AIコンパニオンとの会話 |

知的障害があると暦年齢18歳でも機能発達は10歳以下にとどまるケースが多いため、**Aの設計を厳密にやれば、上位層もカバーできる**。逆は不可。

### 3. 設計原則 6 (10年守る)

1. **エラーレス**: 失敗体験ゼロ、サイレント修正、4段階プロンプティング降下
2. **予測可能性**: ルール・物理・キャラ・UI配置は予告なしに変えない
3. **言語非依存**: 全機能アイコン＋アニメ＋短尺音声で完結。文字必要箇所は親側のみ
4. **ゲームオーバーゼロ**: タイマー、減点、「不正解」表示、完全禁止
5. **コレクションの決定論**: ガチャ・確率報酬は禁止、同行動＝同報酬
6. **ASD+ID をfirst-class、定型児はsecond-class**: 定型児に合わせて妥協する設計判断は採らない

### 8. 反証可能性と Kill Criteria

過度に楽観的な設計を避けるため、各Phaseの**失敗判定基準**を事前に定める。これに到達したら、戦略を変える。

| Phase | Kill Criteria（達成できないなら戦略再考） |
|---|---|
| Phase 0 | 国立成育または東大IRCN共同研究契約が締結できない（権威接続点なし） |
| Phase 0 終了時 | β50家族の累計セッション数が3,000未満（Bayesian事後分布更新の最低ライン）|
| Phase 1 終了時 | 累計DL 500K未満（1M目標の50%）または有料転換率3%未満 |
| Phase 1 終了時 | パイロット研究で適応行動指標の改善が effect size 0.3 未満 |
| Phase 2 終了時 | 累計DL 4M未満 または 月次解約率10%超 |
| Phase 3 終了時 | RCT主要評価項目で対照群との差が有意でない |

**最重要のKill**: Phase 1で**親ダッシュボードを開く保護者率が30%未満なら、成長実感装置の根本再設計**。これはMightier/Otsimoが最後まで解けなかった問題で、Nollaの最大の差別化軸であり最大のリスク。

### 9. 「現代で最高」と言えるための条件

このパネルは、**Nollaが「現代で最高のASD/ID向けサービス」と名乗るために、4つの数字を3年以内に持つ**ことを要求する。

1. **DL数**: 10M（Mightier 100K, Otsimo 1M+, Jade ND 160K の100倍以上）
2. **査読論文**: 2本以上（Toca Boca 0本、Sago Mini 0本、Otsimo 0本、Jade ND 0本に対し圧勝）
3. **MAU/DL率**: 30%以上（Otsimo 1.6-3% の10倍）
4. **保護者継続率（Plus）**: 18ヶ月以上（業界平均6-9ヶ月の2倍）

この4つを同時に達成できれば、Nollaは**世界で初めて「数とエビデンスと粘着の三冠」を取った発達支援サービス**になる。これは現状のいかなる企業も達成していない。

## 補遺: なぜこの設計が「12社全部の詰め込み」ではないか

最後に、AIが陥る「全部の要素を詰め込む」罠を避けたことを明示しておく。

| 取らなかったもの | 理由 |
|---|---|
| ABCmouseの「670,000教室」B2B商業規模戦略 | Nollaの一次顧客は家庭。**ただし特別支援学校 warm-introパイロットは Phase 0 から並行**（Yuya個人ネットワーク経由・無料配布・テスト目的）。商業B2Bチャネル開拓は Phase 4 以降 |
| Toca Boca型「子ども作品のSNSバイラル UGC」 | ASD+ID児の親は子ども作品を公開しない（プライバシー懸念・パフォーマンス問題）。Otsimo/Mightier/Jade/Speech Blubs もUGC機能を持たない構造的理由 |
| 「義肢・車椅子・補聴器」キャラクター対応 | ASD+ID対象セグメントに不要、スコープ希釈 |
| Sago型 3-5体常駐キャラ | 1体（固定の導き手キャラ）+ 自作Nolla で予測可能性は十分担保、MVP スコープ削減 |
| Jade ND型 8領域 中間粒度フィックス | Nollaは L1/L2 でより深く取り、L3/L4 で Vineland 標準に揃える4階層構造を採用 |
| Mightier型 紙レポート（印刷推奨） | 2026 年は LINE/Instagram/PDF 共有が主、紙は売り文句にしない |
| Mightierのarmbandデバイス | DL目標と矛盾、rPPG（フロントカメラ）で代替 |
| Khan Academyの非営利モデル | フリーミアムサブスクと矛盾、ただし無料枠の手厚さで「準・無料」感を担保 |
| Toca Bocaの「No保護者画面」 | 親の成長実感が事業の核、ここはToca Boca哲学を採らない |
| Sago Miniの物理玩具サブスク（Sago Mini Box） | Phase 5以降の拡張余地、初期は不採用 |
| Otsimoの「4プロダクト並列展開」 | 設計原則違反（コア体験の純度を10年守る）、Nollaは1プロダクト |
| Jade NDの診断アイトラッキング（Jade Astea） | 医療機器化が必要、Yuyaの方針に反する |
| Speech Blubsの「人間の顔ズーム」 | ASD児に不快なケース、模倣機能はキャラ顔で代替 |
| Dubuの「cognitive training」フレーミング | RCT失敗の核因、Nollaは「子どもがつくる自分の世界 × AI発達コンパニオン」のフレーミング |
| AutiSparkの量勝負（140+ゲーム） | コア体験の希釈、Nollaは20-40世界に絞る |

**取った要素**は **3つの普遍法則**（コア純度10年・原体験＋権威＋言語非依存・空白地帯）と、**Toca Life World × Sago Mini × Khan Kids × Mightier(機能のみ)** のハイブリッドだけ。

これがNolla 0ベース再設計の全貌である。
